# ModelRoute 官方模型种子

## 业务结论

官方模型目录随代码以版本化 JSON 发布，生产环境不自动抓取官网。当前版本为 `2026-07-23-v2`，绑定 New API `v1.0.0-rc.21` 和源码提交 `bde9b2f44887d34ec54799ae191d50f97914359e`。

种子只收录官方资料能核对 API 标识和价格数字、且固定 New API 能适配的对话或图片模型。官方证据地址只保存在版本化种子中用于发布复核，不进入模型管理业务字段，也不在管理界面显示核价来源、核价时间、币种或生命周期。

## 价格口径

- 管理员录入和种子保存的全部价格数字按一比一使用，不保存币种，也不做人民币与美元换算。
- 文本模型保存每百万 Token 的输入、输出、缓存读取、缓存写入和连续上下文阶梯。
- 图片模型保存“质量 + 尺寸 + 单张价格”矩阵，并按请求中的 `n` 计费。
- 管理界面和市场只显示数值及计费单位，不显示货币符号。

## 官方证据域名

- OpenAI：`developers.openai.com`
- Anthropic：`platform.claude.com`
- Gemini：`ai.google.dev`
- DeepSeek：`api-docs.deepseek.com`
- Qwen：`www.alibabacloud.com`
- Moonshot：`platform.kimi.com`
- Minimax：`platform.minimaxi.com`

种子解析器会校验每条证据地址属于对应厂商官方域名。固定源码交集测试还会校验本地 New API 源码 HEAD 与绑定提交完全一致。

## 暂未纳入

- `gpt-5.4-pro`、`claude-fable-5`、`claude-sonnet-5`：当前没有取得可同时核对 API 标识和 API 单价的完整官方资料。
- Embeddings、已退役模型、语音和视频模型：不属于 V2 上架范围。
- 其他无法由当前 New API 计费表达式准确表示的模型：等待适配和契约验证后再发布新种子版本。

这些条目不使用推测名称或价格。管理员可对自定义模型使用临时地址和密钥执行真实 `hi` 检测，检测成功后再创建。

## 导入规则

- 新模型创建标准模型和首个价格版本。
- 已存在且厂商、协议和当前价格完全一致时跳过。
- 当前价格变化时只追加价格版本，不改写历史版本。
- 已存在模型的厂商或协议与种子冲突时终止导入。
- 全部模型处理成功后写入种子版本和 SHA-256 摘要。

`model-seed` 是 `tools` profile 下的一次性服务。部署脚本会在 PostgreSQL、Redis 和 New API 就绪后执行：

```bash
docker compose --env-file .env --profile tools run --rm model-seed
```

## 验证与回滚

```bash
cd apps/api
go test -p 1 -count=1 ./...

cd ../..
python -m unittest discover -s deploy/tests -p 'test_*.py'
docker compose --env-file .env.example --profile tools config --quiet
```

真实 PostgreSQL 测试使用 `MODELROUTE_TEST_DATABASE_URL`；固定源码交集测试使用 `NEW_API_RC21_SOURCE_DIR`。生产已执行种子后若需整体回退，必须同时恢复同一时间点的平台库和 New API 库备份。
