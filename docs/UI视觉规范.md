# ModelRoute UI 视觉规范

## 视觉定位

ModelRoute 是模型路由运营工作台，优先保证扫描、比较和重复操作的效率。界面使用青绿色作为品牌与主操作色，蓝、绿、琥珀、红仅用于语义状态和指标区分，不使用装饰性渐变、光球或大面积彩色背景。

## 基础规则

- 页面底色使用浅冷灰，内容面使用白色，边界使用低对比度灰绿线。
- 容器圆角保持 `6px..8px`，表格、筛选、表单和分页保持稳定高度。
- 数字、额度、Token、百分比使用等宽数字特性，便于纵向比较。
- 桌面工作区保留侧栏；移动端侧栏变为可横向滚动的紧凑工作区导航。
- 状态、筛选和操作必须有清晰的悬停、聚焦、按压和禁用反馈。
- 厂商图标使用品牌色，未知厂商使用中性图标；图标不改变表格行高。
- 下拉框统一使用浅色表面、紧凑箭头和清晰焦点环；悬停、禁用和分页紧凑尺寸均沿用公共 `Select` 组件，不在业务页面单独改样式。

## 动效

- 页面切换约 `180ms`，弹窗约 `200ms`，菜单和通知约 `120..160ms`。
- 只动画 `transform` 和 `opacity`，不动画布局尺寸、位置或表格列宽。
- 图表柱形只在数据进入时增长一次；表格行不做逐行飞入。
- `prefers-reduced-motion: reduce` 下关闭位移、缩放和图表动画，仅保留即时状态变化。

## 组件验收

- 主按钮、次按钮、文字操作和危险操作具有明确层级，避免所有操作都使用实心按钮。
- 弹窗内部滚动，操作区固定在底部；移动端不能遮挡提交、关闭和检查按钮。
- 表格支持长模型名、长商户名、横向滚动和分页；移动端不能产生根页面横向溢出。
- 空状态、加载状态、错误状态和禁用状态保持与当前上下文一致的语气和颜色。
