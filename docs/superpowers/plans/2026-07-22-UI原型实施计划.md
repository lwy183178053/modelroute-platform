# API 聚合平台 UI 原型实施计划

> **执行要求：** 本计划在当前任务内逐项实施并验证，所有界面文字与交付记录使用中文。

**目标：** 交付一个可在浏览器切换和点击的统一官网原型，用于确认模型市场、用户控制台、商户中心、管理员后台及外围支付管理的 UI 方向。

**架构：** 使用单页 React 原型和本地静态数据，不连接真实接口。页面状态仅用于演示交互；New API 与外围平台的职责边界按已确认设计规范呈现。

**技术栈：** React 19、Vite 6、Lucide React、LobeHub 模型图标、Playwright Core。
