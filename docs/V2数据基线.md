# ModelRoute V2 数据基线

## 适用范围

V2 迁移只用于全新空库。开发环境发布时直接重置 103 的平台库、New API 库和 Redis；101、102 不在操作范围内，本轮不创建新备份或执行恢复演练。

## 核心关系

- 一条商户渠道保存一份上游类型、基础地址和密钥，可同步并绑定多个标准模型。
- 上游模型名称与管理员模型目录规范化后精确匹配；未收录模型只展示，不进入定价和路由。
- 报价按“商户 + 标准模型”唯一激活，同一报价版本为该商户所有绑定该模型的渠道生成独立内部别名。
- 商户倍率使用整数基点，范围为 `0..50000`；`0` 与其他倍率走同一计费表达式。
- 标准模型只支持 Chat Completions、Responses 和 Image Generation。
- 文本价格使用连续上下文阶梯；图片价格使用“质量 + 尺寸 + 单张价格”矩阵。
- 路由策略是用户独立资源，可绑定多把 API 密钥；七天缓存快照按商户模型和渠道模型汇总。

## 健康与支付

- 健康状态下 `next_probe_at` 为空，只有冷却或恢复中的渠道才进入探活队列。
- 人民币支付只保存人民币分和 New API 整数额度，固定换算为 `1 元 = 500000` 额度。
- 账本继续以 New API 整数额度记账，展示层按固定换算显示人民币。
- 提现最低为 `50 元` 且只接受整数，收款方式固定为支付宝。`merchant_withdrawals` 保存申请金额，并由数据库生成 3% 税费和实际到账额度。

## 重置边界

V2 不包含旧迁移的升级兼容分支。103 执行开发重置后，旧平台库、New API 库和 Redis 数据直接退出使用，不保留数据级回滚点。

开发重置只通过 `deploy/scripts/reset-v2-data.sh` 执行。脚本要求 `CONFIRM_V2_RESET=MODELROUTE_V2_RESET_103`，同时校验 103 地址、Git 哈希发布目录、共享数据真实路径和 Compose 项目名；镜像构建成功后直接清理四个固定的 ModelRoute 数据子目录。脚本不接受其他项目路径参数，也不调用备份或恢复脚本。
