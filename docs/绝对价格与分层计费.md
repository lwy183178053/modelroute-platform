# ModelRoute V2 价格与 New API 计费适配

## 业务结论

管理员维护标准模型的基础价格数字，商户为每个模型设置 `0.00x..5.00x` 倍率。平台只负责生成不可变 New API 计费表达式；Token、缓存命中、预扣、退款和最终消费仍由 New API 处理。

## 基础价格

- 文本模型只保存 Token 价格，不在模型目录重复配置接口协议；Chat Completions 与 Responses 由核心服务处理。
- 文本价格按每百万 Token 保存输入、输出、缓存读取、缓存写入和连续上下文阶梯。
- 输入和输出价格必须大于零；缓存价格可为零或不填写。
- 图片模型使用质量、尺寸和单张价格矩阵，单张基础价格必须大于零。
- 全部价格数字不保存币种，不做汇率换算，界面不显示货币符号。

## 商户倍率

商户倍率使用整数基点：

```text
0 基点 = 0.00x
10000 基点 = 1.00x
50000 基点 = 5.00x
```

`0.00x` 与其他倍率走同一报价发布流程和表达式，只在界面显示“免费”。非零倍率折算后的必填价格低于 1 微单位时拒绝发布。

同一商户同一模型只允许一个激活报价，但可绑定多条同模型渠道。每条渠道获得独立内部别名，便于路由健康和结算准确归属。

## New API 表达式

文本报价写入 `billing_mode=tiered_expr`，表达式使用 `len` 选择阶梯，并以 `p/c/cr/cc/cc1h` 计算输入、输出、缓存读取和两类缓存写入费用。当前单一缓存写入数字同时映射到 `cc` 与 `cc1h`。

图片报价根据请求中的 `quality`、`size` 和 `n` 计算单次费用。表达式在同步前执行编译和多组输入冒烟；任一渠道同步失败时恢复 New API 原配置，新版本保持 `sync_failed`，旧报价继续服务。

## 模型删除

无渠道、报价或历史引用的模型可物理删除；存在业务引用时执行归档下架，停止创建新渠道、报价和路由，不删除历史价格与结算依据。

## 验证

Go 测试覆盖单档和阶梯文本价格、缓存项、图片矩阵、多张图片、倍率 `0/1/5` 边界、同步补偿和表达式冒烟。固定 New API `rc.21` 的隔离契约继续验证其原生分层计费、缓存日志和退款日志。
